# Nuked OPL3

Nuked OPL3 1.8 by Nuke.YKT, a cycle-accurate emulation of the YMF262 (OPL3),
from https://github.com/nukeykt/Nuked-OPL3. The files are unmodified.
Licence: LGPL-2.1-or-later (`../../LICENSES/LGPL-2.1-or-later.txt`).

`../src/opl3_nuked.c` drives it as the tracker's OPL3 and adds the circuit
bending on top. The VST plugin offers it next to the FM-1's own OPL3
(`../src/opl3.c`).
